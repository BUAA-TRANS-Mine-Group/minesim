### Static obstacle scenario library and

This library is designed to test obstacle avoidance with static obstacles on mining roads. It records scenarios where the trucks face static obstacles of various sizes on roads with different curves and widths. The focus is on assessing the ability of autonomous mining trucks to plan smooth, efficient trajectories.  

### Benchmark Code 
Task settings and benchmark algorithms are detailed in Code Repository: [MineSim-Static](https://github.com/buaa-trans-mine-group/minesim-static).
